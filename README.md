# SKY CARE ZONE — 초기 웹사이트 구현 가이드

> 이 문서는 초기 프론트엔드 구현을 위한 **최소 명세**입니다. 확정해 적용할 항목은 **사이트맵, 컬러 팔레트, 타이포그래피** 세 가지뿐입니다.

## 프로젝트 개요

- **사이트명:** skycarezone
- **서비스 대상:** 기업·사무실 및 가정
- **서비스 분야:** 에어컨 청소, 공간·가구 클리닝, 방역
- **사이트 언어:** 한국어(초기 적용)
- **디자인 참고 사이트:** https://coastlinecleaningla.com/
- **디자인 방향:** 참고 사이트의 전체적인 시각적 분위기와 콘텐츠 표현 방식을 연구하되, 해당 브랜드의 이미지·로고·문구·코드를 그대로 복제하지 않습니다.

이 문서에 정하지 않은 레이아웃, UI 컴포넌트, 상세 간격, 이미지 구성 및 반응형 표현 방식은 초기 시안에서 자유롭게 제안할 수 있습니다. 별도 요청 없이 기능이나 사실 정보를 확정하지 마세요.

## 1. 사이트맵

### 1.1 페이지 구성

| 페이지 | 경로 | 상태 |
|---|---|---|
| 홈 | `/` | 확정 |
| 에어컨 케어 상세 | 미정 | 임시 개발 경로 사용 가능 |
| 공간·가구 케어 상세 | 미정 | 임시 개발 경로 사용 가능 |
| 방역 케어 상세 | 미정 | 임시 개발 경로 사용 가능 |

서비스 상세 페이지의 실제 URL은 아직 결정되지 않았습니다. 개발 단계에서 임시 URL을 사용한다면 라우트 설정 한곳에 모아 관리하고, 최종 경로가 아님을 명시하세요.

### 1.2 글로벌 내비게이션

메뉴 순서는 다음과 같습니다.

1. **홈** → `/`
2. **에어컨** → 에어컨 케어 상세
3. **공간·가구** → 공간·가구 케어 상세
4. **방역** → 방역 케어 상세
5. **문의** → `/#contact`

브랜드 로고 또는 브랜드명 클릭 시 홈(`/`)으로 이동합니다.

### 1.3 홈(`/`) 섹션 순서

1. **Hero** — 브랜드 및 서비스 소개
2. **Hero 직후 문의 CTA** — Hero와 분리된 영역; `문의하기` → `#contact`
3. **서비스 개요** — `에어컨 케어`, `공간·가구 케어`, `방역 케어` 세 범주; 각 상세 페이지로 이동
4. **신뢰 요소** — 확인된 회사·작업 관련 정보가 있을 때만 표시
5. **문의** — `id="contact"`가 있는 영역

### 1.4 서비스 상세 페이지 공통 섹션 순서

세 서비스 상세 페이지는 모두 다음 섹션 순서를 사용합니다.

1. **작업 절차**
2. **작업 사례(사진)**
3. **유의사항**
4. **문의** — `id="contact"`가 있는 영역

독립된 작업 사례 페이지는 만들지 않습니다. 상세 페이지의 문의 섹션이 있더라도 글로벌 내비게이션의 `문의` 링크는 홈의 `/#contact`로 연결합니다.

## 2. 컬러 팔레트

아래 색상은 변경 없이 CSS 변수(디자인 토큰)로 등록해 전역에서 사용합니다.

```css
:root {
  --color-primary: #286D92;
  --color-accent: #74C7E7;
  --color-secondary: #A4BDAF;
  --color-text: #273740;
  --color-bg: #F9FAF7;
  --color-surface-blue: #E3F1F7;
  --color-surface-sage: #EBF2EC;
  --color-white: #FFFFFF;
}
```

| 토큰 | 역할 |
|---|---|
| `--color-primary` | 주요 강조 |
| `--color-accent` | 밝은 블루 포인트 |
| `--color-secondary` | 보조 세이지 포인트 |
| `--color-text` | 기본 텍스트 |
| `--color-bg` | 기본 페이지 배경 |
| `--color-surface-blue` | 연한 블루 배경 영역 |
| `--color-surface-sage` | 연한 세이지 배경 영역 |
| `--color-white` | 흰색 표면·반전 텍스트 |

참고 사이트의 실제 색상보다 위 팔레트를 우선합니다. 각 색상을 어느 섹션에 배치할지는 초기 디자인 단계에서 결정할 수 있습니다.

## 3. 타이포그래피

- **폰트:** `SUIT Variable`, 대체 `sans-serif`
- **전역 자간:** `letter-spacing: 0`
- **반응형 기준:** 모바일 `<768px` / 중간 `768–1023px` / 넓은 화면 `≥1024px`

| 텍스트 역할 | 모바일 | 중간 | 넓은 화면 | 굵기 | 행간 |
|---|---:|---:|---:|---:|---:|
| Hero 제목 | 36px | 48px | 60px | 600 | 1.25 |
| 섹션 제목 | 28px | 34px | 40px | 600 | 1.30 |
| 카드 제목 | 20px | 22px | 24px | 600 | 1.40 |
| 본문 | 16px | 17px | 18px | 400 | 1.70 |
| 보조 설명 | 14px | 14px | 15px | 400 | 1.65 |
| 버튼·메뉴 | 16px | 16px | 16px | 600 | 1.40 |
| 영문 섹션 라벨 | 12px | 12px | 13px | 600 | 1.40 |

페이지 간 동일한 텍스트 역할은 재사용 가능한 스타일 또는 컴포넌트로 일관되게 적용하세요.

## 4. 적응형 레이아웃

화면 너비뿐 아니라 높이, 방향, 콘텐츠 특성에 따라 레이아웃이 자연스럽게 적응하도록 구현한다.
- 반응형 구간: 모바일 768px 미만 / 중간 768~1023px / 넓은 화면 1024px 이상
- 페이지 좌우 여백: 각각 20px / 32px / 40px
- 기본 콘텐츠 최대 너비: 1200px
- 모바일 세로, 모바일 가로, 태블릿 세로·가로, 데스크톱, 초광폭 화면을 고려한다.
- 각 화면에서 가로 넘침, 콘텐츠 잘림, 과도한 여백이 발생하지 않도록 한다.
- 섹션별 배치 방식과 레이아웃 전환 기준은 디자인 레퍼런스를 참고하여 자유롭게 결정한다.

- 위 네 가지 명세 이외의 디자인 세부사항은 **아직 확정되지 않았습니다**. 참고 사이트를 분석해 첫 시안을 자유롭게 구현하세요.

- 확인되지 않은 작업 실적·후기·인증·연락처·서비스 세부 내용은 만들어 내지 마세요. 콘텐츠가 없다면 임시 표시 상태로 남겨둡니다.
- 문의 영역은 일단 시각적인 자리만 구성합니다. 연락처와 전송 방식이 정해지기 전에는 실제 전송 기능을 구현하지 않습니다.
